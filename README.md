# GEN M Momentos

An **unofficial** community archive for GEN M 2026 creative assets. It is not an official GEN M / MSM website.

## Project Setup

This is a new Astro project scaffolded with basic branding assets inherited from the GEN M ecosystem.

```sh
cd gen-m-momentos
npm install
npm run dev
```

Navigate to `http://localhost:4321` to view the site.
